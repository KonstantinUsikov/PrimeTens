# PrimeTens

Библиотека и приложение Windows Forms для исследования распределения простых чисел на отрезке [2, n]. Каждую задачу можно решить одним из трёх алгоритмов поиска простых чисел и сравнить время их работы.

## Возможности

| Задача | Метод `PrimeTens` | Описание |
|---|---|---|
| Сегменты с min/max простых | `GetMinMaxSegments` | Находит сегменты длины k с наименьшим и наибольшим количеством простых чисел |
| Отрезок без простых | `GetMaxRangeWithoutPrimeNumbers` | Находит наибольший отрезок, не содержащий простых чисел |
| Распределение простых | `GetPrimeDistribution` | Считает количество и частоту простых чисел на k сегментах и выводит их столбчатой диаграммой (ScottPlot) |
| Делители числа | `GetDivisors` | Возвращает все делители числа (окно «Делители») |

## Методы поиска простых чисел

Метод выбирается через перечисление `Prime_Method`:

- **`Erathosphenes`**: решето Эратосфена на `BitArray`, n ≤ `int.MaxValue − 1`.
- **`Division_Lookup`**: проверка каждого числа перебором делителей до √x, n ≤ `int.MaxValue − 1`.
- **`Fast_Lookup`**: оптимизированное многопоточное сегментированное решето (`UltimatePrimesSoE`, класс позаимствован из интернета). Работает с `ulong`, n ≤ `ulong.MaxValue − 1`.

Все методы принимают `CancellationToken`, поэтому долгий расчёт можно прервать.

## Структура решения

| Проект | Назначение |
|---|---|
| `ClassLibraryPrimeTens` | Алгоритмы (`PrimeTens`, `UltimatePrimesSoE`), .NET 6 |
| `WinFormsAppPrimeTens` | Графический интерфейс (.NET 6, Windows Forms, ScottPlot.WinForms 4.1.58) |
| `TestPrimeTens` | Модульные тесты MSTest, в том числе сверка быстрого метода с классическими |
| `ConsoleAppPrimeTens` | Консольный прогон тех же проверок |

## Требования

- [.NET 6 SDK](https://dotnet.microsoft.com/download/dotnet/6.0)
- Windows (для Windows Forms)

## Сборка и запуск

```sh
dotnet build PrimeTens.sln

# графическое приложение
dotnet run --project WinFormsAppPrimeTens

# консольные проверки
dotnet run --project ConsoleAppPrimeTens
```

## Тесты

```sh
dotnet test TestPrimeTens
```

## Использование приложения

1. Выберите задачу и метод поиска простых чисел.
2. Введите n и, если задача его требует, k. Допустимые диапазоны показаны в подсказке на форме.
3. Нажмите «Начать». Пока идёт расчёт, отображается таймер, а кнопка «Прервать» прерывает вычисление.
4. Для задачи распределения откройте диаграмму кнопкой «Вывод».

Ограничения ввода:

- n ≥ 3;
- для диаграммы количество сегментов k ≤ 99999;
- если n не делится на k, приложение округляет n вниз до кратного k, после чего нужно снова нажать «Начать».
